## Build

Open `Altfolio.xcworkspace` (or `Altfolio.xcodeproj`) in Xcode and build the `Altfolio` scheme.
Alamofire 5.12.0 is managed by Swift Package Manager and resolved automatically.
CocoaPods is not required. Keep `Package.resolved` in version control for reproducible builds.
