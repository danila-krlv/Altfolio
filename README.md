## Build

The Xcode project is generated by Tuist 4.207.0. Install [mise](https://mise.jdx.dev/getting-started.html)
and Xcode with the Swift 6.3 toolchain (verified with Xcode 26.6).
The app retains Swift 5 language mode and an iOS 15.0 deployment target.

From the repository root:

```sh
mise install
mise exec -- tuist install
mise exec -- tuist generate
```

Open the generated `Altfolio.xcworkspace` and select the `Altfolio` scheme.
If the active developer directory points to Command Line Tools, set
`DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer` in the shell before running these commands.

Build without launching the app or making API requests:

```sh
xcodebuild -workspace Altfolio.xcworkspace -scheme Altfolio \
  -destination 'generic/platform=iOS Simulator' -configuration Debug \
  CODE_SIGNING_ALLOWED=NO build
```

Use `-configuration Release` for a Release build. Device builds require your own signing team.

Edit `Project.swift` for targets, sources, resources and schemes; edit `Configurations/*.xcconfig`
for the preserved project-level build settings. Run `mise exec -- tuist generate` after changes.
Do not edit generated `.xcodeproj` or `.xcworkspace` files; they are ignored by Git.

Alamofire 5.12.0 is declared in `Tuist/Package.swift`. Keep `Tuist/Package.resolved` in Git.
After changing dependencies, run `mise exec -- tuist install` and regenerate the project.
CocoaPods is not required.

Both test targets are preserved in the shared scheme. Existing coordinator unit tests reference
old initializers and private properties and need a separate update before the test suite can pass.
